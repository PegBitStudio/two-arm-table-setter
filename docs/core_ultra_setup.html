Why bother? Intel's brief says the final demo should run on a Core Ultra Series 2 or 3, and 20 of the 100 points are for OpenVINO optimisation on that hardware — including its NPU (a chip made for AI). Our own laptop is an older i7 with no NPU. This laptop closes that gap.

1Prepare the laptop YOU

about 20 minutes · no typing

  1. Plug it in and keep it plugged in the whole time — speed results change a lot on battery.
  2. Confirm it's a Core Ultra: Settings → System → About → Processor should say "Intel Core Ultra" (Series 2 models have a 200-number, for example "Core Ultra 7 258V").
  3. Check the NPU: press Ctrl + Shift + Esc → Performance. You should see NPU in the list on the left, next to CPU, Memory and GPU.
  4. Update drivers: Settings → Windows Update → Check for updates, then Advanced options → Optional updates → install any Intel items. Restart if asked.
  5. Stop sleep: Settings → System → Power & battery → Screen and sleep → "When plugged in, put my device to sleep after" → Never. Note the old setting so you can put it back.
  6. Space: about 10 GB free on drive C.
  7. Make a work folder: open File Explorer → This PC → Local Disk (C:) → right-click → New → Folder → name it work. (Not Documents or Desktop — OneDrive may try to upload thousands of files.)
No NPU in Task Manager? The NPU driver may be missing — search intel.com for "Intel NPU driver Windows" and install it. You can still carry on; CPU and GPU results count too.

2Install the Claude app YOU

about 5 minutes

  1. In the browser, go to claude.ai/download, download the Windows app and install it.
  2. Open it and sign in with your own account.
  3. Go to the Code tab and choose the folder C:\work as the project folder.
Remember: it's your brother's laptop. You'll sign out at the end (step 10). Never paste passwords or API keys into the chat.

6Try the NPU for the AI parts CLAUDE CODE

about 15 minutes

PASTE TO CLAUDE CODE
Try the NPU in the real robot:
1. brain\run.py --seed 3 --policy --policy-device NPU "put the cup to the right of the plate"
2. brain\run.py --seed 3 --device NPU "set the table"
Tell me if each one really ran on the NPU (the output says which device loaded) and if the table was set correctly. Then, from volunteer_results\results.json, pick the best device for the vision-language model and for the policy for the demo video.
If the vision-language model falls back to CPU, it simply doesn't run on this NPU yet — that's a fine, honest result, and the GPU will be used for the video.

8Voice demo (optional) YOU + CLAUDE CODE

about 10 minutes

Your Speechmatics key should never go into the chat. Add it through Windows settings — no PowerShell:

  1. Start → type environment variables → open "Edit environment variables for your account".
  2. Under User variables click New… → Name: SPEECHMATICS_API_KEY → Value: your key → OK → OK. (Your key is on portal.speechmatics.com under API keys.)
  3. Close and reopen the Claude app so it sees the key.
PASTE TO CLAUDE CODE
Check that SPEECHMATICS_API_KEY is set (don't show it), then run: brain\run.py --seed 5 --audio brain\test_command.wav
Tell me what it heard and whether the table was set.
